RepoScout is a simple repository automation that discovers public GitHub projects and organizes **up to 50 new repositories per UTC day across 12 collections**. Earlier listings remain available while eligible, so the catalog keeps growing.

The repository that runs the automation is **private**. This **public repository shows the results**: the generated website and public catalog data.

**Live site:** [Browse RepoScout](https://kudastech.github.io/reposcout-site/)

- [Collections](https://kudastech.github.io/reposcout-site/topics.html) — explore all 12 collections.
- [Status](https://kudastech.github.io/reposcout-site/status.html) — see catalog counts and how repositories are selected.
- [Related data](https://kudastech.github.io/reposcout-site/assets/related.json) — connections between projects in the catalog.
